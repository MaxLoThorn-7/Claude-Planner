# Claude Weekly Planner

A printable two-page weekly planner with Claude/Anthropic branding.

## How to use

1. Open `index.html` in any modern browser (Chrome, Firefox, Safari, Edge).
2. The planner automatically shows the current week's dates. Today's column is highlighted in orange.
3. Click **✦ Print Planner** (or press `Ctrl+P` / `Cmd+P`) to open the print dialog.

## Print settings

For the best results, use these settings in your browser's print dialog:

| Setting | Value |
|---|---|
| Paper size | **Letter** (8.5 × 11 in) |
| Orientation | **Landscape** |
| Margins | **Minimum** or **None** |
| Scale | **100%** (default fit) |
| Background graphics | **On** (enables orange accents) |

> **Tip:** In Chrome, click "More settings" to find the background graphics toggle.

## Layout

- **Page 1** — Weekly schedule grid, 6:00 AM – 9:00 PM, Monday through Sunday. Each hour row has a subtle half-hour divider line.
- **Page 2** — 18-item to-do checklist (left) + ruled notes area (right).
